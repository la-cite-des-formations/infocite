Dépendances Externes et APIs

Infocite n'est pas un système isolé. Il communique avec plusieurs services tiers pour fonctionner. Ce document liste ces points de contact critiques.

1. Google Cloud Platform (OAuth 2.0)

Rôle : Permet aux utilisateurs de se connecter avec leur compte Google professionnel.

  • Console : Google Cloud Console
  • Identifiants : Client ID et Client Secret (stockés dans le .env).
  • Risque : Si les identifiants expirent, plus personne ne pourra se connecter.
2. Firebase (Cloud Messaging - FCM)

Rôle : Envoi des notifications de bureau en temps réel.

  • Console : Firebase Console
  • Configuration : Fichier firebase-messaging-sw.js à la racine et clés de serveur dans le .env.
  • Vérification : Le certificat VAPID doit être valide pour que les navigateurs acceptent les notifications.
3. Liaison YParéo

Rôle : Synchronisation des identités, des classes et des fonctions.

  • Mécanisme : Import via base de données ou API (selon configuration locale).
  • Champs clés : code_ypareo, code_netypareo, login.
  • Obsolescence : Le système des "Acteurs" est obsolète au profit des codes fonctions YParéo.
4. Google Drive (Embed)

Rôle : Hébergement et intégration des vidéos institutionnelles.

  • Mécanisme : Utilisation d'iframes /preview générées via un resolver d'URL automatique dans TinyMCE.
  • Configuration : Les fichiers doivent être configurés en partage "Tous les utilisateurs de l'organisation disposant du lien".
5. Fontes et Médias
  • Google Fonts : Chargement des polices (Inter, Roboto, Material Icons).
  • Boxicons : Bibliothèque d'icônes pour l'interface.

IMPORTANT : En cas de changement de domaine (URL du site), toutes ces configurations (URL de redirection Google, domaine Firebase) doivent être mises à jour dans les consoles respectives.
