Dictionnaire de Données : Infocite

Ce document décrit la structure de la base de données MySQL d'Infocite. Il est organisé par pôles fonctionnels.

1. Pôle Utilisateurs et Identités

Table users

Table centrale des comptes utilisateurs.

ChampTypeDescription
idbigintClé primaire
identitystringNom complet (Prénom Nom)
emailstringEmail de connexion (ou Google Account)
loginstringLogin YParéo
code_ypareostringIdentifiant unique YParéo
avatarstringURL ou chemin de la photo de profil

Table learners / employees

Extensions des données utilisateurs pour les apprenants et les salariés.

ChampTypeDescription
user_idbigintLien vers la table users
birthdaydateDate de naissance (Apprenants)
positionstringPoste occupé (Salariés)
building / officestringLocalisation physique (Salariés)

2. Pôle Contenus et Rubriques

Table rubrics

Structure de navigation du site.

ChampTypeDescription
idbigintClé primaire
namestringNom affiché
segmentstringPartie de l'URL (slug)
iconstringCode icône Material Design
parent_idbigintLien vers la rubrique parente (hiérarchie)

Table posts

Contenu des articles.

ChampTypeDescription
idbigintClé primaire
rubric_idbigintLien vers la rubrique parente
titlestringTitre de l'article
contenttextContenu HTML de l'article
publishedbooleanÉtat de publication
is_acknowledgment_requiredbooleanSi l'accusé de lecture est activé
is_rating_enabledbooleanSi la notation est activée
is_pinnedbooleanSi l'article est "À la Une"
is_templatebooleanSi l'article sert de modèle (exclu des flux publics)
author_idbigintLien vers le rédacteur (User)
published_atdatetimeDate de mise en ligne prévue
expired_atdatetimeDate d'archivage automatique

Table post_user (Pivot)

Lien entre utilisateurs et articles pour le suivi personnalisé.

ChampTypeDescription
user_idbigintClé étrangère vers users
post_idbigintClé étrangère vers posts
is_readbooleanÉtat de lecture individuelle
ratingintegerNote attribuée (1 à 5)

Table galleries

Albums photos associés aux articles.

ChampTypeDescription
idbigintClé primaire
post_idbigintLien vers l'article (relation 1:1)
imagesjsonDonnées structurées (ordre, chemins, noms)

3. Pôle Organigramme

Table chartnodes

Les cases de l'organigramme.

ChampTypeDescription
idbigintClé primaire
namestringNom de la case (ex: Direction)
code_fonctionstringLien avec le code fonction YParéo
parent_idbigintHiérarchie des cases
format_idbigintLien vers les styles visuels

4. Pôle Droits et Permissions

Table rights / rightables

Gestion fine des permissions.

ChampTypeDescription
namestringNom du droit (ex: manage-posts)
dashboard_rolesintegerMasque binaire des rôles administratifs

5. Pôle Technique et Statistiques

Table interactions

Journal complet des actions utilisateurs (très volumineuse).

ChampTypeDescription
user_idbigintQui a fait l'action
typestringType d'action (view, click, auth)
interactable_type / idstring/bigintSur quel objet (Post, App, etc.)
occurred_atdatetimeHorodatage
