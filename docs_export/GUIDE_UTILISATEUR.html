Mode d'Emploi : Interface d'Usage

Ce guide vous accompagne dans l'utilisation quotidienne d'Infocite, de la gestion de vos alertes à la contribution de contenus.

🚀 PRIORITÉ : Les Notifications de Bureau

Pour rester informé sans avoir à consulter le site en permanence, Infocite vous propose d'activer les notifications de bureau.

Pourquoi les activer ?

Une petite bulle d'alerte apparaîtra sur votre écran dès qu'un nouvel article important est publié, même si votre navigateur est réduit.

Comment faire ?

  1. Rendez-vous dans l'onglet "Infos" (votre profil).
  2. Cochez l'interrupteur "Accepter les notifications de bureau".
  3. Une fenêtre de votre navigateur vous demandera confirmation : cliquez sur "Autoriser".

Personnaliser vos alertes

Une fois activées, vous pouvez choisir :

  • Toutes les notifications : Pour être au courant de tout.
  • Seulement pour les favoris : Pour ne recevoir des alertes que pour les rubriques que vous avez marquées d'une étoile (⭐).
Un problème ? Si les notifications sont bloquées par votre navigateur, un message d'alerte rouge apparaîtra dans votre profil avec une vidéo d'aide pour vous montrer comment les débloquer manuellement dans les paramètres de Chrome/Firefox.

1. Navigation et Recherche

1.1 La page "À la Une"

C'est votre tableau de bord d'actualités. Elle regroupe :

  • Les épinglés : Les 4 informations capitales en haut de page.
  • Le flux récent : Tous les derniers articles publiés.

1.2 Les Favoris (⭐)

Vous pouvez marquer des rubriques ou des articles comme favoris en cliquant sur l'étoile. Ils seront alors accessibles en un clic depuis votre profil.

1.3 La Recherche Globale

Utilisez la loupe en haut à droite pour rechercher un mot-clé. Les résultats affichent à la fois les articles et les applications correspondantes.

2. Mode Édition : Publier du contenu

Si vous disposez des droits nécessaires (Éditeur ou Administrateur), un bouton Crayon (✎) apparaît en haut à droite de chaque rubrique.

2.1 Passer en mode création

Cliquez sur le crayon pour basculer l'interface. Les boutons de gestion apparaissent alors sur chaque contenu :

  • Bouton "+" : Créer un nouvel article ou une application dans cette rubrique.
  • Icône Corbeille (🗑️) : Supprimer un contenu.
  • Icône Crayon (✎) : Modifier un article existant.

2.2 Rédiger un Article

Lors de la création ou modification, vous pouvez :

  • Choisir une icône parlante (Material Design).
  • Définir la date de parution (pour programmer une publication future).
  • Définir une date d'expiration (pour un archivage automatique).
  • Cocher "Épingler" pour forcer l'affichage en haut de page.
  • Activer/Désactiver les commentaires.

2.3 Gérer et Utiliser les Modèles

Pour gagner du temps, vous pouvez utiliser des modèles d'articles (structures pré-remplies) :

  • Appliquer un modèle : En mode création, utilisez le bouton "Appliquer un modèle" pour injecter une structure type dans votre éditeur.
  • Section "Modèles" : En bas de chaque rubrique (en mode édition), vous trouverez vos modèles. Vous pouvez créer un nouvel article directement depuis un modèle ou modifier le modèle lui-même.
  • Extraire comme modèle : Si vous venez de rédiger un article dont la structure est réutilisable, cliquez sur "Extraire comme modèle" pour le sauvegarder dans votre bibliothèque de modèles.

2.4 L'Éditeur Avancé (Blocs intelligents)

L'éditeur d'articles utilise un système de blocs (Notes, Cadres, Titres, Colonnes) pour structurer vos contenus de manière professionnelle.

Aspiration automatique : Si vous sélectionnez du texte (un ou plusieurs paragraphes) avant d'insérer un bloc (ex: une Note), le texte sélectionné sera automatiquement placé à l'intérieur du bloc. Si vous ne sélectionnez rien, le paragraphe sous votre curseur sera transformé.
  • Bouton Dégrouper (Orange) : Présent sur chaque bloc (juste sous la poubelle), il permet de retirer le cadre ou la note tout en conservant votre texte et vos médias à leur place.
  • Sécurité des Titres : Les blocs de type "Titre" ne peuvent pas contenir de listes ou de longs paragraphes. Si vous tentez une action impossible, une notification orange vous en informera en haut de l'éditeur.
  • Raccourcis Clavier : Utilisez Alt + Shift + [Initiale] pour insérer rapidement des blocs (ex: Alt+Shift+N pour une Note, Alt+Shift+C pour un Cadre).
  • Vidéos Google Drive : Pour insérer une vidéo stockée sur le Drive de l'entreprise, utilisez simplement l'outil "Insérer un média" (icône caméra) et collez le lien de partage classique de votre fichier. Infocite se charge automatiquement de transformer le lien pour qu'il soit lisible directement dans votre article.

3. Vos Outils (Applications)

L'onglet "Applications" regroupe tous vos liens utiles.

  • Applications Institutionnelles : Liens officiels (YParéo, Webmail, etc.).
  • Applications Personnelles : Vos propres raccourcis. En mode édition, vous pouvez cliquer sur "+" pour ajouter vos propres liens personnels que vous seul verrez.

4. L'Agenda Événementiel

La rubrique "Agenda" (sous la section "Événements") propose une double visualisation des manifestations à venir :

  • La Timeline (Ligne du Temps) : Affiche les prochains rendez-vous de manière chronologique avec une vignette illustrée (si l'article dispose d'une galerie d'images) et des détails sur le lieu.
  • Le Calendrier Mensuel : Basculable en un clic, il affiche une vue globale classique sous forme de calendrier. Survoler un événement affiche instantanément une bulle d'informations (type, lieu), et cliquer dessus ouvre directement l'article.
Rattachement à l'agenda (Éditeurs) : Dans le formulaire d'écriture d'un article, cochez "Rattacher l'article à l'agenda événementiel" pour définir le type d'événement, la date/heure de début, de fin et le lieu. Cette case est pré-cochée pour tous les articles des sous-rubriques d'Événements.

5. L'Organigramme

L'organigramme vous permet de visualiser la hiérarchie et les visages de l'établissement. Cliquez sur une case pour voir le détail des effectifs et des fonctions rattachées.
